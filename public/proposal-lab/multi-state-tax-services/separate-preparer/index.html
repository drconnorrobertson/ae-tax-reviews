Multi-state tax services: Separate preparer

Clarify coordination when the buyer retains another return preparer. List jurisdictions, entities, transaction facts and the scope of registration and filing work.

Published by AE Tax Advisors. This is an AE-owned proposal comparison resource, not an independent rating or customer review.

What this file should establish

Identify what the new provider supplies and what the existing preparer must evaluate or implement. Ask for the transfer format, communication process and follow-up responsibilities. Neither side's silence establishes acceptance of the work.

List jurisdictions, entities, transaction facts and the scope of registration and filing work.

A situation to work through

A quote covers income-tax filing while sales-tax and payroll questions remain open.

For this situation, start with state activity list. Identify the period and legal owner before combining it with the other records. Keep the original source and explain any adjustments in a separate reconciliation.

Review point

Record what each professional will review and what remains outside scope.

Each professional assumes the other will implement the recommendation.

Question for the reviewer

Who accepts the implementation task and how will disagreements be resolved?

Expected handoff

A two-provider responsibility map.

Separate facts supported by documents from estimates and unresolved assumptions. Assign each missing item to a responsible person and a date. Send the reconciliation alongside the source references so the reviewer can trace each conclusion.
