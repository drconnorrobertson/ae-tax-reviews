Check whether the engagement can answer the question before the decision must be made. Compare the property facts, methodology, report detail and return-preparer coordination.

What this file should establish

Record the actual transaction date, missing inputs and review milestones. Ask the provider to distinguish a target turnaround from a contractual deliverable. Do not assume that buying a service extends a tax or transaction deadline.

Compare the property facts, methodology, report detail and return-preparer coordination.

A situation to work through

Two providers quote different cost pools for the same property.

For this situation, start with property basis. Identify the period and legal owner before combining it with the other records. Keep the original source and explain any adjustments in a separate reconciliation.

Review point

Standardize the facts and distinguish the report from implementation.

The service timeline leaves no time for the buyer's decision.

Question for the reviewer

What can be completed with the available records before the stated deadline?

Expected handoff

A deadline and evidence schedule.

Separate facts supported by documents from estimates and unresolved assumptions. Assign each missing item to a responsible person and a date. Send the reconciliation alongside the source references so the reviewer can trace each conclusion.
