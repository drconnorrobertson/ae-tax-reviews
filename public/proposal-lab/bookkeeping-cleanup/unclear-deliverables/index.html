Bookkeeping cleanup: Unclear deliverables

Turn a broad marketing description into a written service list. Define the accounts, period, reconciliation standard and final deliverables.

Published by AE Tax Advisors. This is an AE-owned proposal comparison resource, not an independent rating or customer review.

What this file should establish

Ask for the actual files, meetings, analyses and implementation tasks provided. Mark items absent from the proposal. Separate an educational discussion from a written recommendation and completed implementation.

Define the accounts, period, reconciliation standard and final deliverables.

A situation to work through

A cleanup fee covers transaction coding but excludes balance-sheet reconciliation.

For this situation, start with account list. Identify the period and legal owner before combining it with the other records. Keep the original source and explain any adjustments in a separate reconciliation.

Review point

State the acceptance criteria before comparing the proposals.

The proposal says strategy without identifying what the client receives.

Question for the reviewer

What specific deliverable establishes completion of the service?

Expected handoff

A deliverable register linked to the agreement.

Separate facts supported by documents from estimates and unresolved assumptions. Assign each missing item to a responsible person and a date. Send the reconciliation alongside the source references so the reviewer can trace each conclusion.
